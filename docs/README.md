# StrategyGame
Игра доступна на русском и английском языке. Просто прикольная игра, но разработка будет долгой. Разработано на Pygame (еще я Java щас изучаю, может для нее будет версия этой игры)
Она будет базирована на контенте Фараон Клеопатра (ну я забыл какое оригинальное название)
Также тут будет чутка майнкрафта, а именно: рандомная генерация по сиду, прокачки как в модах (я про интерфейс) и всякие заводы из модов.
Часть прокачки будут взяты из головы, часть из майнкрафт модов (МАЙНКРАФТ МОЯ ЖИЗНЬ!!!) и часть из одной мобилки, тока название не помню.
Еще боты будут как враги и с другом поиграть можно будет.
