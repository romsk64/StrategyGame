# Документация по коду
## Python
Все очень просто - в файле base.py содержатся все классы и методы, такие как отрисовка.<br>
В файле main.py содержится код, использующий эти методы.<br>
И да, в python я новичок, так что раскладывать все по файлам я не буду, думайте сами что куда.<br>
### base.py
#### **Button**<br>
Класс, который добавляет кнопки, не зависит ни от какого класса<br>
#### **Area**<br>
Класс для добавления простых фигур типа прямоугольника со сплошным цветом<br>
#### **TextArea**<br>
Наследник Area, который просто добавляет текстовую область вместе с текстом *(возможно в будущем я заменю этот класс на Text, который будет просто текстом)*<br>
